# fun_pay_bot
скипт\бот позволяющий удобно продавать telegram stars на площадке funpay. что делает бот? если кратко то делает всю рутинную работу за вас! бот выдает stars через fragment, делает статистику продаж, делает txt документ с ценами конкурентов (для удобности выбора цены), автоматический расчет, выгодно ли продавать stars в данный момент

                                                                          Защита от повторных платежей


                                                                                     
Каждая сделка имеет отдельный этап оплаты.

Если связь пропала во время отправки, сделка замораживается.

Повторная оплата доступна только через отдельную подтверждающую кнопку.
После перезапуска потенциально отправленная транзакция не оплачивается повторно автоматически.
Одновременно в одном чате не может обрабатываться несколько перекрывающихся сделок.
Сделка создаётся только по серверному событию оплаченного заказа FunPay.
